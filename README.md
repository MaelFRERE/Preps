# TriPrep V1

Version personnelle simplifiée, uniquement triathlon.

## Ce qui reste visible
- objectif et date de course
- niveau actuel dans les 3 disciplines
- disponibilités
- semaine en cours
- détail de chaque séance
- export calendrier

## Ce qui a été retiré
- course à pied seule
- HYROX
- tableaux de charge complexes
- graphiques et métriques techniques
- sauvegarde/import avancés
- interface multi-sport

Les calculs restent locaux dans le navigateur. Le plan est une aide à l'organisation et ne constitue pas un avis médical ni la preuve qu'une préparation est suffisante pour terminer une épreuve.
